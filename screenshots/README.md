# Design renders — NOT simulator screenshots

These PNGs are renders of the HTML design preview at iPhone 16 Pro size (393×852 pt @3x),
in light and dark mode, using synthetic sample data. They were produced in a Linux
environment without Xcode, so they are not captures of the running app.

Real screenshots: build `Kira/` in Xcode 26, run on the iPhone 16 Pro simulator and press ⌘S,
or use the previews in `Kira/Kira/Preview/PreviewData.swift`.
