# Vector: training & nutrition companion (iOS)

> *Your intelligent training and nutrition companion.*

Vector combines strength training, programming, rest timers, progress analytics, nutrition tracking and AI meal scanning. Each day it answers four questions:

1. **What am I training today?** Today → Train → Active Workout
2. **What should I lift?** The progressive overload engine, with reasons
3. **What should I eat / how am I doing?** Nutrition, AI meal scan, macro tracking
4. **Am I actually progressing?** Progress analytics, PRs, muscle balance, AI coach

## Getting started

```bash
brew install xcodegen
xcodegen                 # generates Vector.xcodeproj
open Vector.xcodeproj    # set your Team, run the "Vector" scheme on an iOS 17+ simulator
```

- **Sample data:** Profile → *Load sample data* (or pass the `-sampleData` launch argument) loads 8 weeks of realistic training, nutrition and body-weight history, generated by the real progression engine.
- **Pro in development:** in Debug builds, Profile → Developer → *Simulate Pro*. This lasts until the next launch, when StoreKit entitlements are re-checked. To persist Pro, buy through the bundled `Vector.storekit` configuration, which needs no sandbox account.
- **AI meal scanning:** set `VectorMealScanEndpoint` in `project.yml` to your backend URL (contract in `MealRecognition.swift`). If it's empty, a demo recognizer returns a realistic plate so you can try the review flow.

## Tests

```bash
cd Packages/VectorCore && swift test     # 34 tests; runs on macOS or Linux
```

They cover progressive overload rules, PR detection, analytics windows and bucketing, weekly sets per muscle, coach insights (every insight must carry evidence), plan generation for every equipment × frequency combination, nutrition targets, the active-workout state machine, the rest timer, entitlement rules (no upgrade moments during workouts), meal-recognition decoding and persistence round-trips.

## Verification status

- `VectorCore` builds and all 34 tests pass with Swift 6.0.3 (Swift 5.10 language mode).
- The SwiftUI app and widget targets were written without access to Xcode, so they have **not been compiled or run in a simulator yet**. Expect a short round of compile fixes on first build. Previews (`#Preview`) are provided for the main screens with sample, Pro, dark and empty variants.
